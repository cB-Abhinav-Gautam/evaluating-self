# The Evaluating Self

A reader's edition of the sources behind one question: what a person has to keep doing, and keep being able to do, when a machine can produce the work.

**Read it at https://abhinavgautam.in**

Eighty-seven sources, each rewritten as a chapter with hand-drawn figures, grouped by the question it answers. Around the chapters: the claims each one makes, the pairings between sources from different traditions, and the framework of theses and rules derived from the claims.

This repository holds the built site only. Comments on the chapters run through GitHub Discussions on this repository.

Abhinav Gautam
